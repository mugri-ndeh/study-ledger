# Study Ledger

A personal study plan and tracker for a move into Python backend, AI engineering
and ML.

- **The plan:** 7 tracks (Python backend, AI engineering, DSA & LeetCode, ML,
  AWS & DevOps, system design, TypeScript & product), 60 units, 221 steps and
  283 free resources. Every unit runs learn → practice → build → recap.
- **Progressive logging:** each track has one current step. A session always
  counts toward that step, and ticking "I finished this step" moves the track
  forward. Some units wait for a unit in another track (for example RAG waits
  for databases).
- **Today:** picks 2-3 focused blocks from the tracks furthest behind their
  weekly target.
- **Strengths:** recap confidence ratings, LeetCode outcomes (solo, hint,
  solution) and coverage, shown as charts.
- **Projects:** 46 projects from beginner to advanced. 38 are build steps inside
  the plan; the rest are extras.

- **Accounts:** anyone can sign up and start from:
  - **Build a plan for me:** a few questions (goal, experience, depth, hours a
    week, topics). Plain code in `backend/builder/` picks units from a generic
    library of 12 topics and splits the hours. No LLM involved.
  - a **starter template** (generated by the same builder),
  - an **uploaded plan JSON** (the format of Edit plan → Export), or an empty
    plan.

  Everything is theirs to edit afterwards in **Edit plan**. The original plan
  above is a private template that only admins can see or reset to.

- **Market:** demand for 58 skills in engineering job postings. It started from
  a career-ops scan; the app now refreshes it from public Greenhouse, Lever and
  Ashby job boards (36 companies in `backend/market/companies.json`) when the
  latest snapshot is over 7 days old, and keeps every snapshot so you can see
  trends.

- **Backend:** Python 3.13, FastAPI, SQLAlchemy 2.0, Alembic migrations,
  Postgres 17.
- **Auth:** email + password (argon2), httpOnly session cookie, `X-Ledger`
  header on writes against CSRF.
- **Frontend:** React 19 + TypeScript, built with Vite. Charts are hand-written
  SVG.

## Run it with Docker

```bash
cp .env.example .env   # then set POSTGRES_PASSWORD to something random
make up                # builds and starts Postgres + the app; open http://localhost:8000
```

Migrations and the built-in data (templates, skills, first market snapshot) load
on every start. Postgres data lives in the `pgdata` Docker volume. Back it up
with `make backup` (a `pg_dump` into `backups/`).

### Moving over from the old single-user version (once)

The old SQLite file is mounted read-only into the container. This creates your
account with your plan, progress, sessions, projects and skill levels, and makes
it an admin (admins can refresh market data from the Market page):

```bash
make import-sqlite EMAIL=you@example.com NAME="Your name"   # asks for a new password
```

## Deploy (CI/CD)

Every push to `main` runs the tests, builds the image, pushes it to Docker Hub
and tells Portainer to redeploy (`.github/workflows/deploy.yml`,
`deploy/docker-compose.yml`). One-time setup, demo steps and troubleshooting:
[docs/deployment.md](docs/deployment.md).

## Develop

```bash
make setup   # once: Python 3.13 venv, npm install, and a .env if you don't have one
make db      # Postgres in Docker on localhost:5433 (5433 so it doesn't clash with a local Postgres)
make dev     # API on :8000 with reload + Vite on http://localhost:5173
make test    # backend tests, against the ledger_test database
```

Schema changes: edit `backend/models.py`, then
`cd backend && .venv/bin/alembic revision --autogenerate -m "what changed"`,
review the file, and `make migrate`.

Admin commands (`python -m cli …` in `backend/`, or
`docker compose exec app python -m cli …`): `bootstrap`, `import-sqlite`,
`make-admin EMAIL`, `refresh-market`.

API docs are generated by FastAPI at http://localhost:8000/docs.

## Settings (`.env`)

| Name                  | Default | What it does                                               |
| --------------------- | ------- | ---------------------------------------------------------- |
| `POSTGRES_PASSWORD`   | –       | Database password (required)                               |
| `COOKIE_SECURE`       | `false` | Set `true` when served over HTTPS                          |
| `SIGNUP_ENABLED`      | `true`  | `false` closes sign-up                                     |
| `MARKET_MAX_AGE_DAYS` | `7`     | Refresh market data when older than this; `0` turns it off |

## Where things live

| What                                           | File                                                                      |
| ---------------------------------------------- | ------------------------------------------------------------------------- |
| Tables                                         | `backend/models.py`, migrations in `backend/alembic/versions/`            |
| The owner's plan (private template)            | `backend/curriculum.py`, turned into a template by `backend/templates.py` |
| Plan builder: topic library, goals, generator  | `backend/builder/`                                                        |
| Project catalog                                | `backend/projects.py`                                                     |
| Log in, sign up, sessions                      | `backend/auth.py`                                                         |
| Plan editing, export/import                    | `backend/plan_editor.py`                                                  |
| Progression, schedule, today's plan, strengths | `backend/state.py`                                                        |
| Market: job boards, skill patterns, refresh    | `backend/market/`                                                         |
| API routes                                     | `backend/main.py`                                                         |
| Screens                                        | `frontend/src/views/`                                                     |
